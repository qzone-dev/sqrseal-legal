## 2. Service Description

SQRSeal is a mobile security application that allows users to analyze URLs and QR codes for security threats. The application provides the following features:

- Security analysis via manual URL entry
- QR code scanning and analysis
- URL detection from images using OCR technology
- Automatic clipboard content analysis (with user consent)
- Query history and statistics
